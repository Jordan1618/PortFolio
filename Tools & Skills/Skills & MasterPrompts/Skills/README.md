# Skills

**Documentation of the custom Claude Skills I design, refine, and deploy so Claude produces vault-ready output on the first try, without re-explaining the rules every session.**

---

## Main Topics

This directory tracks each Skill I build for Claude : the pain point that triggered it, the original prompt, how it got corrected over time, and its current version.

---

## Goal of this Documentation

- **Track Progress:** Keep a clear record of how each Skill evolved from a rough prompt to a stable, repeatable process.
- **Quick Reference:** Create a library of Skill Docs so I can see at a glance why a Skill exists and what changed.
- **Deep Understanding:** Force myself to write down the reasoning behind each correction, not just apply it.
