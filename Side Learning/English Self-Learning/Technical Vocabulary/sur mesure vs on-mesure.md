# sur mesure vs on-mesure

## Rule
sur mesure in French is tailored, custom or tailor-made in English. on-mesure does not exist.

## Cousins (if relevant)
| Word | Meaning | Example |
|---|---|---|
| tailored | made for one need | tailored financial tracking |
| custom | built for one user | a custom script |
| tailor-made | made exactly for someone | a tailor-made workflow |

## The trap
I translated word for word: sur = on, mesure = measure. Fixed expressions rarely translate word for word.

## Rule of thumb
For a French fixed expression, look for the English chunk instead of translating each word.
