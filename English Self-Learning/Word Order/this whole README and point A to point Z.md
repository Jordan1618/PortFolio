# this whole README and point A to point Z

## Rule
- Use this whole + noun for one object: this whole README, this whole project.
- A letter or a number goes after the noun in English: point A, point Z, plan B, step 2.

## Cousins (if relevant)
| Wrong | Correct | Why |
|---|---|---|
| all this README | this whole README | whole goes after this and before the noun |
| an A point to a Z one | point A to point Z | the letter goes after the noun, no "one" |

## The trap
French says tout ce README and un point A, so the order feels natural. In English the label goes after the noun.

## Rule of thumb
Put whole after this/the/my. Put the letter or number after the noun.
